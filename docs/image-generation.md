# کارت تولید تصویر با AI

کارت `image_generate` متن، عنوان و رسانه ورودی را حفظ می‌کند و تصویر و مشخصات تولید را به آن اضافه می‌کند. مدل تولید تصویر از اتصال انتخاب‌شده خوانده می‌شود؛ فیلد مدل جدا در کارت وجود ندارد. اتصال باید مدل دارای قابلیت تولید تصویر داشته باشد. کلید از اتصال رمزگذاری‌شده همان فضای کاری خوانده می‌شود.

## جریان‌ها

- منبع خبر → بازنویسی AI → تولید تصویر → تأیید انسانی → انتشار.
- منبع خبر → شرط «تصویر ندارد» → تولید تصویر → انتشار. برای مسیر دارای تصویر یک شرط جدا «تصویر دارد» بسازید.
- مجموعه اکسل/گوگل‌شیت → تولید تصویر → انتشار. یک کارت تصویر میان مجموعه و هر مقصد مجاز است. ورود، آماده‌سازی و تأیید داخلی مجموعه حفظ می‌شوند؛ refresh شیت همچنان ورود یا تأیید خودکار نیست. تصویر ردیف هنگام آماده‌سازی واردشده و پیش از تأیید آماده می‌شود؛ تولید فقط در موعد انتشار انجام نمی‌شود.
- برای خروجی‌های متفاوت، دو شاخه با کارت تصویر مستقل و اندازه مناسب بسازید.

## تنظیمات

ابعاد نهایی: یوتیوب ۱۲۸۰×۷۲۰، کاور ریلز و استوری ۱۰۸۰×۱۹۲۰، خبر ۱۲۰۰×۸۰۰، مربع ۱۰۸۰×۱۰۸۰، دلخواه ۲۵۶ تا ۴۰۹۶ پیکسل. خروجی سرویس به ابعاد نهایی برش و تبدیل می‌شود؛ تصویر همیشه JPEG زیر ۲ مگابایت است. کیفیت `low/medium/high` در API ارسال می‌شود، اما پشتیبانی آن وابسته به مدل است.

رفتار: `missing` فقط بدون تصویر، `always` تولید تازه، `edit` ویرایش تصویر ورودی. لینک خراب می‌تواند بدون تصویر حساب شود. دستور از `{{عنوان}}`/`{{title}}` و `{{متن}}`/`{{text}}` استفاده می‌کند. سبک، رنگ برند، تصویر مرجع، لوگو، نوشته روی تصویر و رنگ نوشته قابل تنظیم‌اند. نوشته فارسی و لوگو با Sharp/Pango پس از تولید روی تصویر ترکیب می‌شوند.

تا ۴ تصویر برای هر محتوا قابل درخواست است؛ برخی مدل‌ها فقط یک خروجی دارند. اولین خروجی وارد انتشار می‌شود؛ بقیه در گزارش کارت و پیش‌نمایش باقی می‌مانند. تصویر استوری یا کاور ریلز، ویدئو نیست؛ پشتیبانی انتشار مقصد مستقل است.

## هزینه و سهمیه

تعداد روزانه/ماهانه، سقف هر اجرا و بودجه روزانه/ماهانه در سرور کنترل می‌شوند. سهمیه مدیر سامانه در سطح سازمان نیز بر همه جریان‌ها اعمال می‌شود. روز و ماه میلادی به وقت تهران محاسبه می‌شوند. خالی یعنی نامحدود؛ صفر یعنی بدون سهمیه.

`estimatedCostMicros` هزینه محافظه‌کارانه هر تصویر بر حسب یک میلیونیم دلار است. آن را براساس مدل، کیفیت، ابعاد و تصویر مرجع تنظیم کنید. قبل از فراخوانی، بودجه و تعداد در تراکنش با قفل فضای کاری رزرو می‌شود. بودجه یک کنترل بر پایه برآورد است، نه تضمین سقف صورتحساب بیرونی؛ صورتحساب واقعی ممکن است از برآورد بیشتر باشد. هزینه و توکن گزارش‌شده ثبت می‌شوند؛ بدون گزارش هزینه، مبلغ رزروشده صریحاً برآورد نمایش داده می‌شود. سهمیه تصویر مستقل از سهمیه توکن مدل متنی است؛ تولید تصویر می‌تواند قیمت به‌ازای تصویر داشته باشد.

پس از پایان سهمیه: توقف شاخه، انتظار تا تجدید سهمیه یا ادامه با تصویر موجود/بدون تصویر. انتظار روزانه تا نیمه‌شب و ماهانه تا ابتدای ماه بعد است. در خطا: توقف، بررسی انسانی یا ادامه. تأیید مستقل تصویر در جریان معمولی قابل انتخاب است؛ مجموعه‌ها همیشه تأیید داخلی خود را نگه می‌دارند.

گزارش در کارت، جریان و آمار کلی، شامل تصاویر موفق، درخواست‌ها، خطاها، هزینه و توکن گزارش‌شده است. گزارش رابط حداکثر ۱۰۰۰ درخواست در بازه انتخابی را نشان می‌دهد و این محدودیت را اعلام می‌کند؛ کنترل سهمیه در سرور محدود به این ۱۰۰۰ مورد نیست.

تصویر با کلید محتوا، تنظیمات و پرامپت ذخیره می‌شود. اجرای مجدد همان درخواست از تصویر ذخیره‌شده استفاده می‌کند. نتیجه نامعلوم درخواست بیرونی، خودکار تکرار نمی‌شود و اعتبار رزروشده حفظ می‌شود. خطای HTTP صریح اعتبار را آزاد می‌کند. برای تولید تازه پس از خطا، تنظیمات کارت/محتوا را اصلاح کنید و در مجموعه تغییر ردیف را دوباره وارد کنید؛ درخواست نامعلوم نباید بی‌بررسی تکرار شود.

## سرویس‌ها

OpenAI: `/v1/images/generations` و `/v1/images/edits`؛ OpenRouter: `/api/v1/images` با `input_references`؛ GapGPT: مسیر سازگار OpenAI روی `https://api.gapgpt.app/v1`. مدل و دسترسی تصویر باید در حساب سرویس فعال باشند. تست‌های قرارداد با پاسخ شبیه‌سازی‌شده‌اند؛ موفقیت واقعی GapGPT و هر مدل به پشتیبانی حساب و سرویس وابسته است.

مرجع قراردادها: https://developers.openai.com/api/reference/resources/images و https://openrouter.ai/docs/guides/overview/multimodal/image-generation

## استقرار

۱. API و worker را با migration افزایشی `0014_image_generation.sql` مستقر کنید. اگر `HOOR_AUTO_MIGRATE=false` است، migration را دستی اجرا کنید.
۲. `HOOR_PUBLIC_API_URL` را در worker روی نشانی عمومی HTTPS سرویس API قرار دهید؛ مثلاً `https://api.example.ir`. مسیرهای عمومی رسانه در همین API ارائه می‌شوند.
۳. API و worker باید `HOOR_SECRET_KEY` یکسان و محل ذخیره `YOUTUBE_MEDIA_DIR` مشترک و پایدار داشته باشند؛ این همان زیرساخت ذخیره رسانه یوتیوب است. اگر روی دو کانتینر مستقل‌اند، volume مشترک لازم است. فایل‌ها در زیرپوشه فضای کاری جدا می‌مانند.
۴. تصویر با URL دارای امضای HMAC قابل دسترسی است تا سرویس مقصد آن را دریافت کند. هر کس این URL را داشته باشد می‌تواند تصویر را ببیند؛ مسیر و امضا را در لاگ عمومی قرار ندهید. تغییر کلید رمزگذاری URLهای قبلی را نامعتبر می‌کند.
۵. Docker API و worker فونت Noto Arabic را نصب می‌کنند. اتصال AI دارای مدل تصویر و برآورد هزینه را در کارت تنظیم و ابتدا یک محتوا را با تأیید انسانی امتحان کنید.

آزمون‌ها: `pnpm --filter @socialyar/worker test:images`؛ typecheck وب، API و worker و تست‌های مجموعه، دسترسی و بازیابی اجرا.
